## 1. Hierarki role baru

**Sebelum**

- Superadmin → semua organisasi  
- Manager → full satu organisasi  
- Supervisor / Sales → project sesuai assignment  

**Sesudah**

- Superadmin → semua organisasi (tidak berubah)  
- **Head** → full satu organisasi (menggantikan fungsi manager lama)  
- **Manager** → full **satu project** (fungsi baru)  
- Supervisor / Sales → tetap  

**Kompatibilitas**

- Akun lama `role: manager` tanpa `projectId` otomatis jadi `head`.  
- `manager@proqtrack.id` tetap bisa login, sekarang sebagai **Head**.  
- Akun baru `head@proqtrack.id` (Head) dan `pm@proqtrack.id` (Manager, project `PRJ001`).  
- Worker menerima role `head`; API org-wide (usage/state) untuk Head, bukan project Manager.  
- Database version **13**. Field akun: `projectId` wajib untuk Manager.
